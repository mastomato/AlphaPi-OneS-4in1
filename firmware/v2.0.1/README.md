## 为什么发这一版

2.0 把四枚主页图标统一成「2px 青色描边线稿」，实机上是**倒退**：

- 线稿是在 32×32 画布上按硬阈值填色生成的，**没有覆盖率抗锯齿**。整枚图标只有三种纯色，
  边缘一个过渡像素都没有，贴到屏上就是脏边 + 直楞楞的直角
- 原来那四枚手绘图标本身就带 2~3 级过渡色（例如机身描边的 `0x1926`、`0x32AC`），
  这才是它们看起来干净、有质感的原因

## 这一版怎么修的

| 图标 | 处理 |
| --- | --- |
| 小智 | **逐字节回退**到 1.2.1 / 1.3 用的手绘数据 |
| 收音机 | 同上 |
| 计时器 | 同上 |
| 游戏手柄 | 重绘。保留「暖黄实体机身 + 深色挖空细节」的语言，去掉旧版那 10 个纯红像素、补齐轮廓断口、边缘改为覆盖率抗锯齿混合，尺寸与同排其它三枚对齐 |

配套的源码改动：

- 新增 `tools/desk_icon_game.py`（只生成游戏这一枚，带抗锯齿）
- 旧的 `tools/desk_icons.py` 标为废弃，防止再被误跑覆盖成线稿
- 原生 32px 绘制、四列均分 `4+32+8+32+8+32+8+32+4=160`、不占 PSRAM —— 这几项与 2.0 一致，没动

## 刷机（这块板的两个坑，一直没变）

1. **RTS 接不到 EN**：esptool 那句 `Hard resetting via RTS pin` 是空动作。
   刷完芯片停在 ROM 下载模式，**必须手动把电源拨 OFF 再 ON**。
2. esptool 5.6 在这块板 stub 阶段必失败，用 `--no-stub`（460800，2.6MB 约 3.5 分钟）。

网页刷机：用本目录的 `alphapi-one-s-web-flasher.html`（Chrome / Edge），或双击 `start-web-flasher.cmd`。

## 刷完只需要看一件事

主页下方四枚图标：左起 小智笑脸、游戏手柄、收音机、计时器。确认手柄的形状和分量是否顺眼，
其余三枚应与 1.2.1 / 1.3 上的样子**完全一样**。功能侧不需要重新验证 —— 与 2.0 是同一份代码。
