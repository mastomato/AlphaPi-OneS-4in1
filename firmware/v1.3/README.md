# AlphaPi OneS 桌面 · v1.3「开机自愈与屏幕诊断」（内部 v53）

## 这一版解决什么
有些同型号机器刷完起不来 / 无限重启，而这台板子**没有串口日志通路**（console 走 UART0，
UART0 没引到 USB），所以之前三轮都只能靠推断。这一版把"看不见的失败"变成看得见的信息：

1. **开机诊断页**：每次上电先画一屏硬件事实并停留约 1.2 秒（按任意键跳过）——
   复位原因、这是第几次未确认成功的启动、PSRAM 是否可用及容量、Flash 容量、
   assets 分区是否在、内部堆余量。**UI 起不来也照样能看见，拍张照就能定位。**
2. **启动自愈**：连续 3 次都没活过 20 秒，下一次直接进「SAFE MODE」——
   不初始化界面库、不起 WiFi、不碰音频与收音机，只把诊断页停在那里。
   设备从此不会无限重启；**长按任意键 3 秒**可清零计数并重启重试，
   直接断电再上电也会清零。

## 刷机
- 只刷 app（assets/分区表未变）：`flash_cli.cmd`，写入 `0x20000`。
- 完整刷机：`完整固件/AlphaPi-OneS-4in1-v1.3-full-8MB.bin` 写到 `0x0`。
- **刷完必须手动断电再上电**（这块板 RTS 接不到 EN，刷完停在 ROM 下载模式）。

## 已知取舍
- 每次开机多约 1.2 秒诊断页停留。这是为定位"别人机器起不来"故意付出的代价。
