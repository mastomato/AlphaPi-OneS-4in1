## 一、新增节拍器（在计时器页里）

**入口：主页按 D 进计时器，再长按 B 切到节拍器。** 不是新图标、新页面，就是计时器页的
第二个子界面，长按 B 来回切换（切进去后底部会提示"长按B 回计时器"）。

| 项 | 说明 |
| --- | --- |
| 速度 | 40 ~ 240 BPM，每档 5 |
| 拍号 | 2/4、3/4、4/4、5/4、6/4，屏幕上一排拍点就是小节拍数 |
| 重拍 | 每小节第一拍音高更高（1568 Hz），其余拍 1047 Hz，靠听就能分辨小节头 |
| 画面 | 28px BPM 数字 + 拍点（点亮 140ms）+ 拍内进度条 |
| 配色 | 这一页以暖黄为主色，拍点用青色做对比 |

键位：**A 起停 · B 切换编辑项（BPM / 拍号）· C 减 · D 增**；长按 A 复位 120 BPM，
长按 B 回计时器，长按 D 回主页。

拍点用绝对时间网格累加，不按"上一次 + 间隔"算，UI 循环 20ms 的调度抖动不会累积成
节奏漂移；偶发欠拍（例如刚切回这一页）不补打，但会回到原来的时间网格上。

## 二、倒计时有了读秒声

跑表时每秒一声短促的"嗒"，**最后 3 秒音高抬高**（1700 Hz），到点仍是原来的三声提示。

- 开着计时的时候**直接按 B 就能开关读秒声**（提示行显示"B静音 / B开声"）。
- 停止状态下按 B 把编辑项轮到"读秒声"，用 C 关、D 开。
- 开关状态存在 NVS，下次开机保持。
- 在小智页 / 收音机页后台走表时不会响：半双工链路上抢先写音效会打断正在进行的
  识别或收流。

## 三、游戏音效补全

之前只有"死亡 / 结束"能听到，因为那几声是 160~260ms 的长音，而碰撞、按键、得分
全是 18~30ms 的短音——短流在 N32 上还没开播就被判为一段会话结束。

本版把游戏音效统一重做：

1. **新增 `type=2` 音色**：方波 + 指数衰减包络（60ms 落到底），听感是"嗒 / 叮"而不是"嘟"。
   刻意用方波而不是正弦：这台小喇叭上一直能听到的就是方波，正弦短音基本听不出来。
2. **`type=2` 的流至少持续 160ms**：音调本身仍然短，补的是尾部静音——只是让芯片
   来得及开播，不改变音色。
3. **每个动作都有声**：蛇转向、方块左右移动 / 旋转、砖块碰撞、挡板反弹、小鸟拍翅、
   吃食物、消行、过关，各自有区分的音高（280 ~ 1000 Hz）。
4. 死亡 / 结束音保持原来的低频长音不变。

## 四、配网界面：关掉热点时显示路由器地址

关掉热点后，配网页中间那行从原来一直挂着的 `192.168.4.1` 改成：

```
路由 192.168.1.23
```

也就是**这台设备从家里路由器拿到的地址**。上面一行同时显示设备当前连的家庭 Wi-Fi 名。
没连上就显示 `未连接路由`（暖黄）。STA 掉线时地址会清零，不会拿旧地址骗人。

## 五、配色

计时器与节拍器页加了暖黄：跑表时数字与进度条转暖黄（时间在走 = 暖色），节拍器的
BPM 数字、重拍点、进度条同色，青色留给拍点和编辑态。

## 六、还需要实机确认

本版改动集中在音频时长与音色上，编译通过不等于耳朵过关：

1. 游戏的碰撞音、按键音是否真的能听到（这次把流长从 253ms 收到 160ms、
   音调从正弦换成方波 + 衰减）。
2. 节拍器在 40 / 120 / 240 BPM 三档下的节奏稳定性与音色。
3. 倒计时读秒声是否与结束三声衔接自然。
4. 240 BPM 时每拍 250ms、音效流 160ms，理论上不会互相吞，但要看实机。
